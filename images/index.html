Where each file goes

Animated README title: use sodapop-title.gif with its PNG as a still and reduced-motion alternative. The existing wide banner remains available for static layouts.

OAuth app: upload sodapop-oauth.png under Application logo and set Badge background color to #09090B. The PNG is 512 x 512 and below GitHub's 1 MB upload limit. GitHub's badge guidance.

Repository: use sodapop-repo-social.png in Settings > Social preview. It is 1280 x 640 and below 1 MB. Use sodapop-banner.svg for a README header instead. GitHub's preview guidance.

Landing page: use the transparent mascot, the appropriate light/dark logo lockup, and the favicon set. Point social metadata to the published absolute URL of sodapop-og.png; uploading this folder alone does not configure the page.

Keep the identity intact: preserve proportions, retain the icon's breathing room, and use cyan as an accent rather than replacing the primary pink/purple gradient. This is Sodapop's own artwork, not an official GitHub, Copilot, or Charm badge.

Editable sources and export information

make brand runs source/animate.py to create the looping title from the finished PNG artwork, without external fonts. When rebuilding everything, run it after the static exporter and finalizer so the asset manifest also includes the animation.

Every SVG is a self-contained vector master with outlined lettering. It needs no fonts, scripts, remote images, or network connection to display. The PNGs are ready for upload; the WebP files are lossless web exports. The asset manifest includes dimensions, palette values, and file sizes.

Optional regeneration sources are in source/build.cjs and source/finish.py. The artwork exporter uses @resvg/resvg-js@2.6.2 with locally licensed Avenir Next and Menlo font files supplied as arguments. The finalizer uses Pillow for WebP and ICO output. These tools are separate from the Go application; no font files or renderer dependencies are bundled here.
